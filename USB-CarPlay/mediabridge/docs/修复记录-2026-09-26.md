## 追加修复

- `ArtworkHelper.clearCache()` 先使所有活跃 `ArtworkRepository` 失效，再删除文件；旧任务在写入前后都必须通过 cache version 检查，避免清空后旧封面回写。
- 应用图标也改为临时文件写完后原子改名，避免 provider 读取到半个 PNG。
- 后台 IPC 队列有固定 worker、每条 lane 有界容量和按 key 合并；Binder 卡死无法由 Android 强制终止，系统只能保证 UI 和重试状态机不被拖死，并在任务关闭时丢弃后续工作。
