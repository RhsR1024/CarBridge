# 2.3.7 车机来源显示名

只将车机来源目录 AppSourceInfo.appName 和空/正常播放信息 MusicPlaybackInfo.appName 改为“媒体桥接”。Android 应用名称、桌面图标、MediaBridge 设置入口、包名、token、来源类型、图标 URI 和控制策略保持不变。

目录维护按包名找到原条目，名称变化时原位更新并读回确认，保留其他来源；不通过删除重建来源改变身份。旧车机 UI 缓存可能需要重新打开小窗后刷新。名称只影响车机展示，不用于控制身份匹配。

用户要求修改前先提交推送；基线 main 为 327203e。保留 2.3.6 的播放器入口/设置分离和切源续播。

验收：下拉列表与媒体来源显示“媒体桥接”；桌面仍为 MediaBridge / MediaBridge 设置；切源续播、方控、小窗放大和设置入口正常。最终 APK、签名及测试结果见交付 manifest.json。实际 UI 缓存刷新需实车确认。
