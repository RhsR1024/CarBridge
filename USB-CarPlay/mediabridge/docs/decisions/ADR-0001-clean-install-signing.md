# ADR-0001：采用卸载原版后的全新安装路线

- 日期：2026-09-25
- 状态：已接受

## 旧要求

SPEC/PLAN 原本以同包同签名覆盖升级为发布闸门，目的是保留原版设置和通知监听授权，并准备同签名回退包。

## 问题证据

本地参考 MediaBridge APK 证书 SHA-256 为 `C8A2E9BCCF597C2FB6DC66BEE293FC13F2FC47EC77BC6B2B0D52C11F51192AB8`，本工程测试证书为 `50E0F1A99A029CCD9A843333D5BB07BD0099415B3532DF6BB7ED2017DC64D822`，仓库没有已证明匹配参考证书的私钥。

## 决定

用户明确允许先卸载原版，再全新安装本工程 APK。本次自用交付不再等待同签名私钥，也不把覆盖升级作为阻断。

## 未选方案

- 继续等待原签名私钥：无法确定可获得时间。
- 更换 applicationId 并与原版共存：会改变 ECARX 兼容身份和 provider/metadata 行为。
- 伪称可覆盖：安装会被 Android 拒绝，不可接受。

## 兼容影响

卸载会清除原版 SharedPreferences、缓存和通知访问授权。新版本首次安装按新安装默认值启动，用户必须重新打开通知访问。因此旧配置迁移、授权保留和同签名覆盖不计为已通过，只作为用户豁免范围记录。

## 回退与测试

卸载前备份车机当前 APK、版本和设置截图。若新版本异常，卸载本版本后安装备份原版，并重新完成原版授权。该流程必须在目标车执行一次后，才能将 G10 回退标记通过。
