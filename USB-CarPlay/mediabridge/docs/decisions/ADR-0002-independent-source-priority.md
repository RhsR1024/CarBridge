# 独立媒体来源与忽略名单优先

日期：2026-09-30，更新：2026-10-01。状态：独立包名接入小窗及第三方桥接已由用户实车确认并授权合入主线；26100101 的来源名称和 CarPlay 空会话修复待本车验收。

用户要求 MediaBridge 与车机商店网易云共存，并明确原生来源由页面的“应用忽略名单”决定。此次要求替代 SPEC/PLAN 中沿用网易云包身份的旧发布路线。

## 身份与目录

正式 applicationId/namespace 改为 `com.mediabridge.app`，调试版为 `com.mediabridge.app.dev`。移除网易云身份、语音别名和应用凭据声明；封面 authority 和内部事件按实际 applicationId 区分。保留 Java 组件类名不代表继续使用网易云安装身份。

音乐客户端仍以 Context 的实际包名注册。随后通过已连接的 EAS Binder 和车机系统 Flyme 音乐 APK 内的接口，读取 AppSourceConfig，合并自己的包名/名称/图标/sourceType 6/priorityLevel 1，写回并核验。保留其他来源，包括官方网易云，不删除旧来源、不改变忽略名单。空目录或接口失败不覆盖系统目录，状态页单独展示登记结果。此接口为车机私有接口，成功构建不等于目标固件接受写入；目录整表更新无跨进程 CAS，不能承诺抵御其他应用同时修改目录。

## 目录维护（26093003）

客户端注册成功后启动独立目录维护器。首次确认后按 15 秒、45 秒、240 秒间隔复核（相对首次确认约 15 秒、60 秒、5 分钟），随后每 5 分钟只读检查。仅缺失、重复或自身配置不一致才读取当前整表、合并自身并写回；每次实际补写后重新开始延迟复核。目录为空不写入。

未就绪、读回不一致、接口不可用、异常及繁忙统一按 15/30/60/120/300 秒退避，之后保持 300 秒重试。10 秒超时会取消任务后续写入，忽略迟到结果并安排重试；同步 Binder 调用仍未退出时保留单任务占位，继续记录等待，避免并发写和无限增加线程。同步调用若永久阻塞，当前进程不能强制终止它，此时日志明确显示 TIMEOUT/WAITING，不能宣称恢复成功。断链、重连旧实例及停止桥接都会取消维护，不删除已有目录条目。

诊断记录 reason（registration/delayed_verify/periodic_verify/retry）、result（PRESENT/ADDED/UPDATED 等）、missingAfterConfirmation、目录读写数量和下次检查间隔。PRESENT 只表示接口读到正确条目，ADDED/UPDATED 表示本次写入并立即读回成功，均不代表小窗 UI 已刷新。维护器不接触 requestPlay、播放器控制或焦点仲裁；让位期间仍维护目录。

## 选择与让位

“应用忽略名单”与“收藏忽略名单”保持独立，不根据扫描到的目录自动勾选应用。忽略应用 PLAYING/BUFFERING 时优先于自动/固定第三方选择；原有自身和媒体回路过滤继续保留。

26100101 固定 MusicPlaybackInfo.appName 为 MediaBridge，与目录及图标保持同一来源身份；实际第三方名称保留在 PlayerSnapshot 和应用页面，曲目、封面及控制目标仍来自选中的第三方。

针对本车 CarPlay（com.flyme.auto.energy）增加空控制会话例外：MediaMetadata 为空，或标题/显示标题/媒体 ID/歌手/专辑均为空且时长不大于零时，不作为可桥接输入，也不作为忽略名单中的持续播放证据。该规则同时作用于自动、固定和暂停回退选择，且不修改用户名单，不泛化到其他音乐应用。其曲目元数据有效时恢复常规名单规则。车机焦点回调仍是独立的让位依据，即便 CarPlay 没有曲目元数据也会让位；随后需要第三方的新播放事件才能接管，不能靠旧状态或目录复核抢回。该例外识别的是已确认的空控制会话形态，不能凭缺少元数据断言 CarPlay 物理上没有声音。

SESSION_GUARD 仅在空控制会话状态变化时记录；SOURCE_IDENTITY 在输出切换输入播放器时记录固定来源身份和输入名称，避免把动态播放器标签误认为安装包或目录名称变化。

让位后保留来源目录条目，停止播放数据输出和车机命令转发。忽略应用暂停、旧会话元数据变化、设置刷新与自动重连均不能把旧 PLAYING/PAUSED 会话当作新播放意图。未忽略应用的新播放事件才能恢复。车机主动切换其他来源时，也通过焦点回调与运行时查询让位。

## 安装和验收

新包是独立应用，设置及通知访问不从旧包自动继承。安装后为新 MediaBridge 开启通知访问；在应用忽略名单勾选希望自行接入车机的网易云、Wayfarer 等播放器。旧网易云包名的 MediaBridge 应先在其页面停止桥接，避免两套桥同时运行。若该旧桥占用了官方网易云包名，需要用户自行备份并处理旧桥，才能安装同包名的官方网易云；此任务不自动卸载任何应用。

本车验证：目录出现 MediaBridge 且保留官方网易云；第三方播放/暂停/上下曲/收藏/歌词/封面；忽略播放器与第三方交替播放；双方会话同时存活；原生收音机或其他来源切换；监听重连和媒体服务重连；重启后目录和桥接恢复。验证登记读回、UI 实际可见及方控闭环，分别记录结果。

测试签名 APK 用于实车验证，不宣称车机兼容性已完成验收。回退可停止新桥并重新启动旧桥；不自动迁移或删除旧应用数据。
