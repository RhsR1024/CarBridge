# 改包网易云收藏红心试验（26092807）

## 实测背景与判断

用户在车上以 MT 管理器改包、重签的官网下载网易云车机版 `com.netease.cloudmusic.iou`（6.2.81）播放成功，MediaBridge 可桥接方控，但小窗没有收藏红心。MediaBridge 设置页“显示收藏”下提示“当前播放器未提供可用的收藏操作，原车入口已隐藏”。这表示桥接侧拿到了可辨别的收藏状态，却没有确认可写操作；不能据“车机版”这一身份直接推定 Android MediaSession 暴露了收藏接口。`mediabridge-probe-20260928-130352-368.log.txt` 中该会话的 `PlaybackState.actions=0`，尚不能证明 `setRating()` 一定无效。

## 试验行为与风险边界

只对 `.iou` 放宽红心显示条件，且仍要求收藏状态已知、没有待确认请求。点击红心时先按既有通知按钮、自定义动作、明确支持的评分动作处理；若都不存在，则试发一次 Android `TransportControls.setRating()`。评分类型优先取播放器声明或元数据；均未提供时试用 HEART。调用返回仅表示请求已发出，**不代表播放器已收藏**。仍等待最多 3 秒的播放器状态回传，超时会标记状态未知并隐藏入口，不会伪造成功。酷我、汽水、LX、酷狗等播放器的收藏判断和控制路径保持不变。

“探测改包网易云”按钮还会记录 `.iou/.iov` 会话的评分类型、评分元数据、`ACTION_SET_RATING` 位、自定义动作 ID/标签、通知操作标签/可执行性、当前桥接收藏状态和“显示收藏”开关。另记录车机收藏能力声明结果和红心点击回调。探针不主动执行收藏动作；只有车机小窗实际点击红心才发 `setRating()`。

## 车上验证

1. 在 MediaBridge 中开启“显示收藏”，让 `.iou` 播放一首**未收藏**歌曲，确认小窗是否出现红心。记录红心初始状态。
2. 打开 MediaBridge，点击“探测改包网易云”；回小窗点红心一次。随后到网易云应用内确认歌曲是否真的进入收藏，再观察小窗红心是否变化。不要只凭按钮点按动画判断成功。
3. 若应用内已收藏，再点探针一次；尝试取消收藏并核对应用内结果。若点按后红心消失或提示状态未知，等 3 秒后导出诊断日志，不要连续反复点击。
4. 导出诊断日志，重点查看 `FAVORITE_PROBE`、`Favorite sent`、`Favorite confirmed`、`Favorite confirmation timed out`、`Unsupported media command` 与 `ECARX_PROBE`。若播放器没有任何评分回传，则需根据探针发现的实际私有动作继续适配，不能仅强制显示红心。
