# 蓝底应用图标

`original-blue.webp` 保留修改前的 432×432 原图。车机照片中，蓝色圆角方块被放进白色长方卡片；资源核对确认自适应图标背景为白色，前景原图也自带白色外缘。

26093002 将原图中的银色音符、星环和两颗星光提取为透明前景，四个自适应图标入口统一使用 `@color/ic_launcher_background`（`#0B4DBB`）。背景由桌面按自身遮罩铺满，前景沿用原来的画布尺寸和位置。五种密度的普通/圆形位图入口也生成无白边的蓝底版本。

重新生成资源：安装 Pillow、numpy 后，在仓库根目录运行 `python scripts/generate-launcher-icons.py`。脚本从固定原图提取银色区域并保留其原有明暗；不得直接替换原图而不重新检查提取区域和三个形状的种子点。

本轮已完成透明前景与长方形示意图的人工检查、Release 构建、Lint 和最终 APK 资源/签名核验。示意图不代表车机截图，目标桌面的裁切比例和缓存刷新仍需安装后确认。
