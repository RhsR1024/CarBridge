## 暂停、切歌和重连

MediaBridge 的 retainPaused 会清空当前 snapshot 并关闭普通控制；过去只有 PLAY 的恢复入口。现在明确 PLAY/NEXT/PREVIOUS 可以从保留卡片重新寻找当前真实协作会话，检查连接、权限、来源选择、generation 和 inputEpoch 后发送。断开的旧卡片不能发命令；命令不缓存等待下一连接。

暂停连接在让位状态下仅准备控制对象，不发布抢占媒体源，不申请音频焦点。USB 已连接且桥接就绪时，即使还没有歌曲也发布带当前 `usb.media.connection` 的 PAUSED 控制会话；MediaBridge 只接受与已认证协作连接一致的标记，继续过滤原 APK 空会话和旧连接标记。连接本身不发送播放。

明确切歌成功后：USB 新适配委托原 NEXT/PREVIOUS 回调，再在先前暂停时调用原 PLAY；纯软 CarBridge 通过 `PlaybackPolicy.userSkip()` 请求现有播放资格，后续 PAUSE 仍可取消尚未完成的请求。播放中切歌不额外抢焦点。本轮用户已明确授权这一切歌后播放行为。

## USB 原设置列表

三项设置直接放入原 ScrollView 列表：媒体接入、缺失歌手时的标题格式、直连在线封面与歌词。复用原行/标题/值样式，保留原 root、工具栏、控件和绑定，不再增加顶部独立栏。原资源及布局文件不改写。

默认仍“保留原始信息”。对于截图“雷佳 - 人世间”，请选择“歌手 - 歌曲名”，立即显示歌名“人世间”、歌手“雷佳”，无需重新连接。仅修改显示/查询副本，不回写盒子原始字段、曲目 ID 或 USB 数据。已有独立歌手时不拆分。

直连在线资源默认关闭；需要时开启，车机须联网。桥接使用 MediaBridge 的在线开关与来源选择。播放器原生封面和歌词优先。

## 歌词逐级兜底

1. 原歌名 + 歌手 + 时长。
2. 若失败，去除歌名中的英文 `()`、中文 `（）` 及其中说明，再以歌名 + 歌手 + 时长查询。
3. 再失败，以处理后的歌名 + 歌手查询，不要求时长。

无括号时跳过重复查询；时长未知时直接按身份查询，并可继续去括号。括号处理仅用于歌词检索，不改变小窗标题或协议数据。歌手始终参与核对，正时长容差为 3 秒。无时长兜底允许同歌名/歌手的另一版本，可能与现场版或剪辑版时间轴不同。

MediaBridge 每一级先查完已启用且有精确身份匹配器的网易、QQ、LrcLib，再降级；CarPlay 不使用尚无该匹配器的酷我/Zvuk，普通播放器原行为不变。直连客户端使用 LrcLib 相同顺序。缓存身份升级为 lyrics-v2，避免旧失败缓存挡住新规则。请求取消和曲目代次保护保留。封面没有跟随歌词放宽时长/歧义规则。

## 进度条边界

手机 CarPlay 拖动后的进度上报继续同步。本轮未增加车机小窗反向指定播放时间：USB 现有回调只有快进/快退，没有验证过的绝对时间指令；纯软虽有相关协议名称，也没有已验证的完整发送/确认链。没有用其他视频播放接口或猜测 USB 指令冒充支持。

## USB 保持边界与源码

固定基线 7,545,236 字节，SHA-256 `10dc853023f48cf0a11f44f99a6da1dd64cb08010550e0b1a72e8030cf94d796`。新包保留原签名与版本字段，用设置标记区分。
