# CarBridge 两项媒体配置是否适合 USB CarPlay

结论：根据本次日志和当前使用方式，**这两项都不是三项故障修复的前提，本次不迁移**。USB 桥接资源由配套 MediaBridge 负责。是否需要扩展 USB 直连显示，应以实际使用模式和数据形态决定，不能因纯软 CarBridge 有开关就直接照搬。

## 缺失歌手时的标题格式

CarBridge 实现：`shared/src/main/java/com/shilapi/xcertplay/nowplaying/CombinedTitleMetadata.kt`；选项为“保留原始信息”（默认）、“歌手 - 歌曲名”、“歌曲名 - 歌手”。只在歌手为空、标题不超过 512 字且不含换行、恰好一个带两侧空格/制表符的横线分隔时拆分。已有歌手、多个分隔符或普通连字符均保持原样。设置在重新连接后应用，协议原始存储不改写。

它适合这些情况：

| 实际上报 | 有用的选择 | 作用 |
| --- | --- | --- |
| title=`周铁男 - 三国杀`，artist 为空 | 歌手 - 歌曲名 | 得到 title=`三国杀`、artist=`周铁男`，小窗显示及在线查找可以使用 |
| title=`三国杀 - 周铁男`，artist 为空 | 歌曲名 - 歌手 | 按用户确认的顺序拆分 |
| title=`三国杀`，artist=`周铁男` | 保留原始信息 | 数据已经完整，不拆 |
| title 为旧歌名，artist 为新歌名/新歌手 | 三项都不能修复 | 属于字段错位/不同歌曲的增量混合 |
| title 是动态歌词，artist 为空 | 不应靠格式设置猜歌名 | 需要检查手机音乐软件的车载蓝牙歌词设置或真实歌曲字段 |

USB 原协议已有独立 `MediaSongName`、`MediaArtistName`、`MediaAlbumName`、`MediaLyrics`。用户日志 18:09:08.794–18:14:22.064 的 60 次 USB 元数据记录中，13 次歌手为空，但 **0 次标题包含上述可识别的分隔形式**。因此该设置对这份实测没有可用输入，也不会修复“如愿/如愿”或旧歌名配新歌手。

若未来换手机音乐应用后明确出现稳定的合并格式，可以增加这个可选兼容设置，默认仍保留原始信息。应只处理输出快照，并保持原始增量合并、曲目代次、封面关联和盒子通信不变；不能将拆出的歌手回写原始状态，否则下一次增量到达可能被误认为换曲。

## 直连在线封面与歌词

CarBridge 实现：`common/src/main/java/com/shilapi/xcertplay/media/DirectMusicResources.kt`。开关默认关闭，仅实际走 DIRECT 时生效；桥接由 MediaBridge 负责。它要求歌名、歌手及正时长，使用 LrcLib 查歌词、iTunes 查封面并核对身份/时长；原生图优先，缓存有数量限制，异步结果按曲目代次校验。

| 使用场景 | 是否需要 USB 自己在线补全 |
| --- | --- |
| MediaBridge 桥接，或自动模式当前已选择桥接 | 不需要；开启 MediaBridge 的资源检索即可，USB 再查一遍会重复请求与缓存 |
| F25 直连，或自动模式退回直连；想要车机原生小窗封面和歌词 | 有价值；此时 MediaBridge 不负责该来源资源，须由 USB APK 完成补全及输出 |
| 主要看 CarPlay 内的音乐界面/封面，只用方控 | 不是必需；这个功能只补车机 Android 媒体小窗，不能为手机投屏界面增加封面/歌词 |
| 车机无互联网，仅手机 CarPlay 连接正常 | 在线功能不能保证可用；需要车机自身可访问资源服务，原生数据和缓存仍可使用 |

USB 当前 `F25Direct.update` 只发布标题、歌手、专辑及播放状态。其 SDK 虽提供 `getArtwork`、`getLyricContent`、`getCurrentLyricSentence`、`getDuration` 和进度接口，但新直连层尚未完整接入。完整扩展需要：

1. 原生封面/歌词/可信进度先接入 F25 输出，提供车机可读的封面 URI 和读权限。
2. 有界缓存、下载限制、超时取消、换曲/断连隔离，以及歌词同步。
3. 独立开关默认关闭，只在 DIRECT 时查找，桥接时退出自身请求。
4. USB 日志的时长原本全部为 0，不能照搬 CarBridge 的正时长门槛；应等采样确认，或使用与配套 MediaBridge 一致的唯一精确匹配。没有可信进度时不能承诺同步歌词。
5. 全量验证新增内容不进入 USB 命令链、不更改方控或系统焦点，并实测 F25 小窗读取封面权限。

因此“直连在线封面与歌词”是可选的直连能力扩展，不是一个开关就能获得的现成功能。本次原生封面/歌词和严格在线补全针对 **USB → MediaBridge → 车机** 路径；不宣称 DIRECT 已具备同等资源显示。
