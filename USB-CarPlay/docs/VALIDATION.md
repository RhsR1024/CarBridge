## 实车状态与建议验证

用户已确认此前多点触控补丁可双指缩放。新增三模式尚未在用户的车机与 USB 盒子上实测；本地测试不替代真实的车机 SDK、盒子固件和系统焦点行为。

建议依次验证：

1. F25 直连：手机连接、音乐/导航音频、连续上一曲/下一曲、暂停后等待数秒、再播放及双指缩放。
2. 桥接：安装配套 MediaBridge 并授予通知使用权，验证歌名/歌手/专辑、小窗及方控；暂停后仍能播放。
3. 自动：MediaBridge 启用/关闭与忽略名单变化，确认状态提示及单通道接管。
4. 播放期间切换模式、断开重连、MediaBridge 重启，确认 USB 连接、音频和触控保持正常。

如发现新增媒体接入问题，覆盖安装固定精简基线即可回退。没有新增时长换算、定位播放或未经确认的封面关联，相关限制见 [使用说明](USAGE.md)。
