# CarBridge 0.1.6 — 设置页间距修复

日期：2026-10-03；versionCode 106；上游基线仍为 DiPlay 0.2.10 / main 4556313。

选择项原本通过额外的空白 View 在下方留出 12dp，普通按钮则在上方设置间距。两种控件混排时，普通按钮后接选择项、两个音道按钮连续出现等情况会缺少间距；反向排列又可能叠加留白。

本次让选择项使用下边距，并在设置分组构建完毕后统一相邻按钮的总间隔为 12dp，计入已有下边距，避免重复叠加。说明文字、开关行、分组边距和按钮高度保持原设计。

覆盖刷新接入状态与标题格式、媒体与导航音道、恢复图标与播放／暂停、诊断按钮、权限按钮，以及 BYD 仪表自动设置与主题等按钮组合。条件设置重新渲染时同样应用统一间距。没有修改设置保存、音频、方控或歌曲处理行为。

验证：mobile release 与 automotive debug 构建成功，mobile release lint 0 错误／4 个既有警告；差异、文档链接和 public tree 检查通过。新版 APK 已核对原包名、106 版本号、与 0.1.5 相同的签名及运行时认证资产。此轮仅布局改动，未新增测试或重复运行上一轮完整音频／连接回归。构建证据见交付目录的日志与 manifest.json。本机没有连接车机，因此没有将本轮修复记为实车视觉验收。
