# CarBridge 0.1.0 配套安装与车测说明

日期：2026-10-02。本机实现、测试和构建完成；这是待实车验收的测试签名配套包。

## 安装包

交付目录：`D:\WorkSpace\CarPlay\deliverables\CarBridge-0.1.0`。

| 安装包 | 应用 ID | 版本 |
| --- | --- | --- |
| CarBridge-0.1.0.apk | io.github.rhsr1024.carbridge | 0.1.0 / 100 |
| MediaBridge-2.3.0-carbridge-26100201.apk | com.mediabridge.app | 2.3.0-carbridge-26100201 / 26100201 |

先更新 MediaBridge，再安装 CarBridge。MediaBridge 保持原应用 ID；CarBridge 是新应用，可与原版 DiPlay 共存，原 DiPlay 配置和权限不会自动迁移。此次没有对车机执行任何安装或卸载。

两包使用 C 盘本机 Android 测试证书，已核对与历史 `MediaBridge-main-29f8c17-26092810.apk` 同证书，但未读取车机当前安装版本。优先覆盖安装并保留数据；若系统报告签名不兼容或禁止降级，先保留现有版本和配置并核对当前版本，不以卸载绕过后再声称配置保留成功。CarBridge 运行时认证资产来自用户指定原版 APK，未随源码存放。

启动 MediaBridge，按其原有流程确认通知读取和车机桥接服务已启用；需要小窗时保持原有悬浮窗授权。启动 CarBridge，按原有连接流程授予相关权限并连接 iPhone。测试时选 CarBridge 建立连接，避免原 DiPlay 同时占用连接。

## 推荐设置

CarBridge 设置中的“车机与媒体接入”：

- “车机适配”：**吉利 / ECARX**（默认）。
- “媒体接入方式”：**自动（跟随 MediaBridge）**（默认）。
- “音乐互斥”：**开启**（默认，替代旧音频焦点开关语义）。
- “直连在线封面与歌词”：按需开启，默认关闭；仅直连时查询，可能发送歌名、歌手、专辑和时长。关闭仍使用原生资源及缓存。
- 配套新版无需开启“旧版手动直连已配置”。

| 想要的效果 | CarBridge 设置 | MediaBridge 设置 | 实际使用 |
| --- | --- | --- | --- |
| 通常由 MB 桥接，随忽略名单切换 | 自动 | 不忽略 CarBridge 且服务就绪 | MB 桥接歌曲卡片、资源与方控 |
| 自动切到直接方控 | 自动 | 忽略 **CarBridge** | CarBridge 直接注册 ECARX |
| 固定直接方控 | ECARX 直连 | 保持原忽略名单即可 | 新版协商临时排除；不改持久名单 |
| 固定 MB 桥接 | MediaBridge 桥接 | 取消忽略 CarBridge，启用桥接服务 | 忽略冲突时显示原因并等待处理 |
| 未安装 MB | 自动或 ECARX 直连 | 无 | 独立 ECARX 路线；仍取决于车机服务可用 |

忽略原版 **DiPlay** 不等于忽略 **CarBridge**。直连后，CarBridge 歌曲由车机媒体接口展示，MediaBridge 不再负责这个来源的小窗与控制；它仍可服务其他音乐软件。两种路线中的实际接入状态在 CarBridge 设置内查看，必要时点“刷新接入状态”。未知退出或交接失败时先停止该来源输出并显示等待，不能把超时当成成功接管。

连接、重连和迟到 PLAYING 不自动抢占音乐。首次连接或切换路线后若保持暂停，在手机主动播放，或点“播放 / 恢复 CarPlay 音乐”。其他应用后一次主动播放时 CarBridge 应停止自己的声音并向手机发暂停；重新主动播放 CarBridge 才能取回。普通 Android 应用无法强制暂停所有不遵守焦点的第三方应用，具体播放器的独占效果须实测。

## 歌曲、封面、歌词和返回图标

歌曲文字、状态和进度来自 iPhone 的 Now Playing；原生封面已接入 iAP2 session 12。是否下发、支持的格式和播放器行为需要实车确认。桥接模式沿用 MediaBridge 现有封面/歌词设置；直连可选择在线补全。未匹配或无网络时保留可用缓存，不用其他版本或上一首的资源填充。

歌词支持有时轴 LRC、暂停冻结、跳转及时间偏移；没有原生歌词字段的假设，也不保证所有曲目都有歌词。直连在线命中要求歌名/歌手匹配及接近的时长，现场版和录音室版不能随意互换。

Geely 默认返回按钮使用用户参考图上方的纯黑车标，无下方中英文。原自定义图标和名称优先；需要切回新默认时点“恢复车型默认返回图标与名称”，然后重新连接 iPhone。点击继续走返回车机桌面的原有行为。BYD 功能保留，但仅在 BYD 车型启用。

## 实车验证次序

1. 记录 ROM、Android、iOS、手机播放器、两个 APK 版本，确认 CarPlay 正常连接、触摸、声音和返回桌面。
2. 在桥接模式测试歌名/歌手、封面、歌词、暂停/继续/seek，以及方控单按和快速两次按键；对照手机确认每次只执行一次。
3. 从其他车机音乐主动播放，再主动播放 CarBridge；听音确认只有后来主动播放的音乐，同时观察手机是否暂停。加入来电、Siri、导航测试。
4. 忽略/取消忽略 CarBridge，及显式直连/桥接，共切换至少 20 次；记录实际路线、方控是否重复、是否有短暂双播。
5. 在直连测试新应用身份是否被 ECARX 接受、车机媒体卡片与回调；启用在线资源后测试命中、无歌词、离线缓存及快速换曲。
6. 测试前后台、断开重连、MB 或车机媒体服务重启，以及更新安装和配置保留。BYD 设备回归另行记录。

完整标准见 [V01–V26](CARBRIDGE_VALIDATION.md)。出现异常时，记录操作时间、当时路线与使用的播放器，导出 CarBridge 诊断及 MediaBridge 日志；诊断中区分命令已提交与随后观察到手机状态，不能用“发送成功”代替执行确认。
