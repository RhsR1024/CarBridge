# CarBridge 0.1.8

暂停状态明确切歌成功后，通过现有 PlaybackPolicy 请求播放资格；播放中不重复申请，断联拒绝，后来的暂停取消待完成意图。这是用户本次明确要求的行为更新，替代此前“切歌不申请播放”的规则。MediaBridge 2.3.12 同时修复暂停/让位后的控制入口丢失，需配套升级。

直连歌词按原歌名+歌手+时长、去中英文括号及说明后的歌名+歌手+时长、处理后歌名+歌手（无时长）逐级查询。只影响查询，不改显示标题；封面匹配门槛不变。缓存版本升级，原生内容优先、取消/代次边界保留。

USB 客户端设置、控制、歌词和不变边界见 [R2 修复说明](../USB-CarPlay/docs/CONTROLS_R2_2026-10-03.md)。小窗反向绝对时间 seek 本轮未实现，需要验证真实 CarPlay 控制链，手机进度上报不变。

三包源码、测试及签名验证完成后交付，纯软 APK 位于仓库外 deliverables。认证资产与签名私钥不提交。本地证据见 [汇总](../USB-CarPlay/docs/evidence/controls-r2-release.json)，仍待实车验收。
